## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- whatsapp-business-agent
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/whatsapp-business-agent /tmp/whatsapp-business-agent
mkdir -p ~/.claude/skills && cp -r /tmp/whatsapp-business-agent/skills/whatsapp-business-agent ~/.claude/skills/
```

**Per project:** copy `skills/whatsapp-business-agent` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/whatsapp-business-agent/SKILL.md) into your rules or system prompt.
